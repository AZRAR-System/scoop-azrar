# AZRAR Scoop bucket | مخزن Scoop لـ AZRAR

```powershell
scoop bucket add azrar https://github.com/AZRAR-System/scoop-azrar
scoop install azrar
```

English: Installs AZRAR silently (needs admin). Updates via `scoop update azrar`.

العربية: يثبّت AZRAR بصمت (يحتاج صلاحيات المدير). التحديث بالأمر أعلاه.
